## What's new

- **Find and replace everywhere:** Edit › Find… (Cmd+F) and Find and Replace… (Cmd+Option+F), also in the command palette, in every kind of file. In a CSV table a bar above the grid searches every row, even in a 100,000-row file, can match case, whole cells or only the selected columns, and one Cmd+Z takes back a Replace All. From rendered Markdown or an HTML preview, it moves to the source and searches there.
- **Multiple windows:** drag a tab out of the window, or choose Window › Move Tab to New Window, to give a file a window of its own. Cmd+Shift+N opens an empty window. Closing one window while others stay open asks about its unsaved files first.
- **Windows come back where they were:** quitting brings every window back at the next launch, in the same place and at the same size.
- **Smaller windows:** a window can now shrink to 560 by 420, half of a MacBook Air's screen.
- **Files Left Open:** File › Files Left Open chooses what happens to the files open when you quit: reopen them where they were (the default), list the unsaved ones to restore, or ask about unsaved ones when quitting.
- **Open Recent:** File › Open Recent lists the last 10 files you opened or saved under a new name, and so does the palette. They also appear in macOS's Recent Items, under full in the Dock and in the Apple menu.
- **Split editor:** Option+S, or View › Split Editor, shows a second editor of the same file beside the first. In Markdown and HTML it takes the rendered side's place.
- **Line numbers:** Option+L, or View › Line Numbers, shows or hides them.
- **Fixes:** Open With offers full for Python files again on Macs where Python's IDLE is installed. A file whose edits were undone just before closing no longer comes back with those edits.
