## What's new

- **Reopens as you left it:** quitting or closing the window no longer asks about unsaved work. Every open file, saved or not, comes back at the next launch, in the same order and with its view, cursor and scroll position.
- **Markdown formatting:** keyboard shortcuts for bold, italic, code, code blocks, headings, lists, quotes and links, on both sides. Alt+B shows an optional formatting bar.
- **HTML preview:** Cmd+Option+1 or 3 shows a read-only preview of an HTML file next to the code or instead of it. Scripts never run, and images from the internet load only when you allow them. Links open in your browser.
- **Export:** Markdown to HTML and CSV to Excel, through the save panel. The open file isn't changed.
- **Zoom:** Cmd+=, Cmd+- and Cmd+0, remembered between launches. On Spanish and Catalan keyboards, Cmd+Shift+0 zooms in too.
- **View keys:** Cmd+Option+1, 2 and 3 switch Markdown and HTML between side by side, source only and rendered only.
- **Shortcut list:** Alt+K, or `?` in the command palette, lists every shortcut. Type to search it by action or by key.
- **Find panel:** restyled, and now readable in dark mode.
- **Fixes:** Cmd+click on a link no longer selects the paragraph. File icons are sharper at small sizes in Finder.
