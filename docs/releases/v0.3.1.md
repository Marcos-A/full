## What's new

- **Pasting into a selection in a table:** a value pasted into several selected cells now goes into every one of them, not only the first, and one Cmd+Z takes the paste back. A copied block repeats to fill the selection when the selection holds whole copies of it, as in spreadsheets; otherwise it goes in once at the top-left corner.

## Documentation

- Both READMEs (English and Catalan) describe pasting into a selection in the table, give 0.3.1 as the version in the download check and the build information, and note that the public download check hasn't been run for v0.3.1 yet.
