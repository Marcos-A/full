## What's new

- **Separate cells in a table:** Cmd+click (Ctrl+click on Windows and Linux) picks cells that aren't next to each other, and Cmd+drag adds a whole block, as in Excel. Shift+click extends the newest block, and Cmd+click on a selected cell takes it out, even from the middle of a range. Delete clears every picked cell, and one Cmd+Z brings them all back. A pasted value fills each of them. Blocks that share the same rows or the same columns copy as one table; for any other mix, full explains why it can't copy them. Cmd+click on a row number or column letter adds that whole line to the picked cells.
